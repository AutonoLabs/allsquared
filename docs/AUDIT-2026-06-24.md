# AllSquared End-to-End Audit — 24 Jun 2026

## Executive Summary

AllSquared is a **substantial UK freelance contracts MVP** with real backend depth (payments, escrow, disputes, admin, R2 storage, AI) but had **uneven frontend wiring** and **documentation drift**. This audit streamlined the stack, unified integrations, and incorporated legal templates into the primary contract builder.

## Recommended Stack (implemented / confirmed)

| Layer | Recommendation | Rationale |
|-------|----------------|-----------|
| **Database** | **PostgreSQL + Drizzle** on **Neon** | Already in use; serverless-friendly, type-safe ORM, UK data residency options |
| **Document automation** | **DocuSeal** (self-hosted) | Open-source, UK B2B suitable, already integrated in `signatures` router; DocuSign as enterprise fallback |
| **LLM** | **Server-side OpenAI** via `trpc.ai` + **LexAI RAG** for legal grounding | Rate-limited, authenticated; no client-side API keys |
| **Templates** | `legal/` + `templates/` → DB seed → builder UI | Single source of truth in PostgreSQL `contractTemplates` |

## What Was Removed (bloat)

| Item | Reason |
|------|--------|
| `server/firebase.ts` + `firebase-admin` | Superseded by Cloudflare R2; never imported |
| `server/routers/contractChat.ts` | Duplicate of `trpc.ai.chatMessage` |
| `client/src/pages/NewContract.tsx` | Orphaned; not routed |
| `client/src/pages/ComponentShowcase.tsx` | 1,300+ line dev-only page, no route |
| `axios`, `openai` npm pkg, `@material/material-color-utilities` | Unused dependencies |

## What Was Fixed

1. **Sentry middleware** — `app` was referenced before `express()` initialization (runtime crash).
2. **Template seeding** — Boot now runs `seedAllTemplates()` (legal + `templates/` dir).
3. **Contract signing** — `contracts.sign` handles markdown and JSON content via `shared/contract-content.ts`.
4. **Category enum** — Builder no longer sends invalid `service_agreement` category.
5. **Draft contracts** — `totalAmount: 0` allowed for incomplete drafts.
6. **Template rendering** — Unified `[VAR]` and `{{var}}` syntax in `shared/template-render.ts`.
7. **LLM** — `ContractChatbot` now uses `trpc.ai.chatMessage` (Squario), not `window.__openai_key`.
8. **E-sign UI** — `ContractDetail` routes to DocuSeal/DocuSign when configured, internal signing otherwise.

## Architecture (simplified)

```
User → Clerk Auth → React SPA (Vite)
                      ↓ tRPC
                 Express API
                      ↓
    ┌─────────────────┼─────────────────┐
    PostgreSQL    DocuSeal/OpenAI    Stripe/R2
    (Drizzle)     (sign + AI)        (pay + files)
```

## Contract Creation Flow (unified)

1. **Template** — Pick UK legal template or scratch
2. **Parties** — Companies House lookup + UK address
3. **Modules** — Scope, payment, escrow, IP, disputes, etc.
4. **Details** — Per-module questions
5. **Review** — Save draft → Contract detail → E-sign or internal sign

Classic typeform path remains at `/dashboard/contracts/new/classic`.

## Remaining Gaps (not in this PR)

- KYC UI in Profile is stubbed (backend exists)
- Escrow UI not wired to `trpc.escrow` (Transpact backend ready)
- PDF export not implemented
- `partyAId`/`partyBId` schema columns unused
